# 日报模板

写入 `daily/YYYY-MM-DD.md`。按需删减小节，但保持「今日新增 / 改动摘要 / 改动量 / 遗留」的骨架。

```markdown
# YYYY-MM-DD 工作日报

**仓库：** <repo-name>　**分支：** <branch>　**范围：** <today | 区间>

## 今日新增
- <新增功能/文件/模块，一句话说清做了什么、为什么>
- ...

## 改动摘要
- <对已有代码的关键修改及其影响>
- ...

## 改动量
- 提交数：N　文件：M　+X / -Y 行
- 新增文件：
  - path/to/new_file

## 遗留 / TODO
- <未完成项、临时方案、后续跟进点>

## 备注
- <可选：踩坑、决策、待讨论>
```

## 填写要点

- **今日新增** 强调「新出现的东西」；**改动摘要** 强调「对旧代码的调整」。
- **改动量** 的数字取自 `git diff --stat` / `git log --stat` 的汇总行。
- 一天多次运行时，追加 `## HH:MM 增补` 小节，不覆盖上文。
- 面向未来的自己：写清楚「为什么这么做」，而不仅是「改了哪个文件」。
